## Integrantes

## Descripción
Este repositorio contiene la resolución de los retos prácticos correspondientes al tema de eventos e interfaces gráficas en JavaFX:

- **Reto 1**: Sistema para la gestión e inventario de productos.
- **Reto 2**: Sistema para el control y registro de lotes de café.
- **Reto 3**: Sistema para la gestión y registro de ventas de productos.

## Requisitos
- Java JDK 21 o superior
- Maven (o utilizar el wrapper `mvnw` incluido en cada carpeta)

## Instrucciones de Ejecución

Cada reto se encuentra en su propia carpeta y puede ejecutarse de manera independiente.

### Reto 1
```bash
cd Reto1
./mvnw javafx:run
```

### Reto 2
```bash
cd Reto2
./mvnw javafx:run
```

### Reto 3
```bash
cd reto3
./mvnw javafx:run
```

> Nota: En Windows, sustituir `./mvnw` por `mvnw.cmd` o utilizar directamente `mvn javafx:run`.
